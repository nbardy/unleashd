Historical review found two requirements that a coordination-only redesign can accidentally lose. First, the owner wanted each Buddy to retain self-managed working hypotheses and durable general lessons; task state belongs in authoritative work records, but that does not justify deleting Buddy memory or forcing all learned preferences into owner-edited soul. A scoped design can preserve portable personal long-term learning plus workspace/case context, while explicitly acknowledging that provenance cannot prove free-text non-disclosure. Second, detailed notes should retain useful attempts, failures and exploration, separately from dense memory, server audit and raw transcripts. Long authored reports can use immutable artifacts or linked note sections without silent reduction. The wave_sim sample also distinguishes one manager from many collaborators, top-level placement from access, and a demo prerequisite from authorization to send customer email.
