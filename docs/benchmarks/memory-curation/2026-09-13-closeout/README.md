## Lessons to preserve

- Prompt activity, memory writes, saved source, loaded runtime and deployed behavior
  are distinct observations. Existing receipts do not identify a prompt version.
- A successful-turn reviewer cannot learn from a failed turn it never receives.
  That is an admission question, not evidence that another prompt would fix it.
- Same-audience correction notes can exist while compact memory stays stale.
  Cross-audience isolation does not explain every freshness problem.
- Whole-document revision-checked replacement already supports cleanup; another
  delete operation is unnecessary. Preserve useful older knowledge and uncertainty.
- Save relocated evidence before removing its source. Reuse exact native refs;
  an ISO/UUID note name is not automatically a filesystem path.
- Keep decision actor, accepted/proposed distinction, rationale and reconsideration
  conditions. Later caveats can narrow valid positive evidence without erasing it.
- Temporary assistant-selected task limits belong in work/history; durable owner
  policies may legitimately contain exact numerical limits. Blanket deletion loses
  information, and memory never grants authority to bypass runtime limits.
- Test retention, retrieval and applied behavior separately. Keep probes/rubrics,
  full history and later corrections out of fresh-reader context.
- Repeated tuning on the same histories does not create independent evidence.
  Paraphrased known cases remain robustness probes. Preserve failed candidates and
  report per-case regressions, grading identity and uncertainty.
- The original grades were unblinded Development Lead inspection. They were not
  an independent calibrated judge or human-certified assessment.
- Private corpus preservation, synthetic regression construction, exact replay,
  production cross-conversation portability and held-out evaluation are distinct.
  Missing historical state must be labeled, never reconstructed silently.
